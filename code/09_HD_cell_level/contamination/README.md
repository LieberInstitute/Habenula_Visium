We noticed that Banksy cluster 11 in the optimal clustering results, while
mostly registering to astrocytes, had some signal for MHb and was completely
spatially located there (unlike the other 2 astrocyte clusters). We were
suspicious about the fact that the MHb is quite dense, and cell bodies are
crudely estimated in bin2cell by naively looking around the nucleus-- pointing
at possible contamination of transcripts from nearby MHb neurons. This directory
aims to use code to evaluate this contamination hypothesis.
